Diccionario Fácil de IA
💬 Prompt / Petición
Es la pregunta, foto o texto que el usuario envía a la IA para que la resuelva.
🧠 Nodo IA (Servidor)
Es el cerebro robot. Recibe el prompt, piensa la respuesta y se la manda de vuelta al usuario.
⚡ Acelerador GPU (GHz)
Son las zapatillas turbo del robot: mientras más GHz tenga, más rápido piensa y responde.
🎒 Memoria VRAM
Es la mochila del robot: le permite guardar modelos de texto, imágenes y video al mismo tiempo.
🌐 Canales API
Son los teléfonos del nodo: determinan a cuántos amigos puede atender en simultáneo sin hacer fila.
📚 Base Vectorial (RAG)
Una súper biblioteca donde la IA busca datos reales para responder con precisión y sin inventar.
❄️ Kit de Enfriamiento
Pensar intensamente calienta las GPUs. ¡Úsalo cuando el nodo esté naranja antes de que falle!
