# AI Constructor Laboratory

Simulador interactivo y laboratorio de infraestructura de Inteligencia Artificial para educación STEAM desarrollado y personalizado por Play Code.

Aprende sobre Nodos de IA, memoria VRAM, aceleradores GPU Tensor, inferencia, replicación de modelos, balanceo de carga y bases de datos vectoriales (RAG).

## 🚀 Despliegue

Este proyecto está configurado para desplegarse en [Vercel](https://vercel.com).
